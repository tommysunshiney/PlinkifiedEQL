## Vision

Plinkified EQL Command Center is designed to be far more than a combat parser.

Its goal is to become a complete adventure companion by combining:

- Adventure Journal
- Live Combat Parser
- DPS Analysis
- Session Statistics
- Screenshot Integration
- ShareX Support
- Camp Tracking
- Loot Tracking
- Character Progress
- Widget-Based Dashboard

The philosophy behind the application is simple:

> **"Most important information in two seconds."**

The application should provide an immediate overview of the player's adventure while allowing deeper analysis whenever desired.
