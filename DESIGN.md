# Plinkified EQL Command Center Design Principles

These principles guide every design and development decision made for this project.

---

## 1. Most Important Information in Two Seconds

The user should understand what is happening immediately after looking at the application.

Information should be prioritized by importance, not by technical complexity.

---

## 2. Every Screen Answers One Question

Each screen or tab should have one clear purpose.

Avoid clutter by keeping unrelated features separated.

---

## 3. No More Than Two Clicks

Frequently used actions should never require unnecessary navigation.

If something feels buried, redesign it.

---

## 4. The UI Must Never Fight the Player

The interface should reduce workload, not create it.

The player should spend time playing EverQuest—not operating the companion app.

---

## 5. The Parser Never Blocks the UI

Log processing should always happen in the background.

The application should remain responsive at all times.

---

## 6. Protect User Data

Never overwrite, delete, or modify EverQuest log files.

User settings should be preserved whenever possible.

---

## 7. Human-Readable Settings

Configuration should be understandable without reading documentation.

Whenever possible, use descriptive names instead of technical jargon.

---

## 8. Build Features That Earn Their Space

Every feature should answer one question:

"Does this help the player understand their adventure faster or better?"

If the answer is no, reconsider adding it.

---

## 9. Working Software Before Perfect Software

A simple feature that works is better than a complex feature that never ships.

Iterate and improve over time.

---

## 10. Document Discoveries

If we learn something important while developing, document it.

Future us should never have to solve the same problem twice.

---

## Project Philosophy

Plinkified EQL Command Center exists to enhance the EverQuest Legacy experience without distracting from it.

The application should feel lightweight, reliable, informative, and enjoyable to use.
